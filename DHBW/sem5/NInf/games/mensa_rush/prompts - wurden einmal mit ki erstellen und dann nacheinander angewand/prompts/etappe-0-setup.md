# Etappe 0 – Setup (Grundgerüst)

## Prompt (kopieren & einfügen)

```
Erstelle ein Browser-Spiel in EINER einzigen HTML-Datei mit dem Framework Phaser 3 (per CDN eingebunden, https://cdn.jsdelivr.net/npm/phaser@3.80.1/dist/phaser.min.js). Keine externen Dateien, keine Build-Tools.

Das Spiel heißt "Mensa-Rush: Das letzte Schnitzel" und spielt in der DHBW-Mensa.

Anforderungen für diese erste Version:
- Feste Spielfeldgröße 1280x720, Arcade Physics, Draufsicht
- Dunkler Hintergrund, Spielfeld zentriert auf der Seite
- Titel des Spiels als Text oben im Spielfeld
- Eine einzige Phaser-Scene mit preload/create/update
- Noch KEINE Spiellogik, keine Spieler – nur ein leeres, sauber laufendes Grundgerüst
- Alle späteren Spiel-Konstanten (Geschwindigkeiten, Zeiten etc.) sollen später zentral in einem CONFIG-Objekt oben im Script landen – lege dieses Objekt schon jetzt an (vorerst leer bzw. mit Kommentar-Platzhaltern)

Liefere die komplette HTML-Datei. Sie muss ohne Fehler im Browser laufen (Chrome/Firefox).
```

## ✅ Abnahmetest
- Datei im Browser öffnen → Spielfeld wird angezeigt
- Browser-Konsole (F12) zeigt **keine** Fehler
