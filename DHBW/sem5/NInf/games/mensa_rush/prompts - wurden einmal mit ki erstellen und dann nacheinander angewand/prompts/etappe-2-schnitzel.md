# Etappe 2 – Das Schnitzel

## Prompt (kopieren & einfügen, aktuelle HTML-Datei anhängen)

```
Hier ist meine bisherige Phaser-3-HTML-Datei (Mensa-Rush mit Arena und 2 Spielern). Erweitere sie, weiterhin alles in EINER HTML-Datei mit Phaser 3.

Baue jetzt das Schnitzel ein:

1. Auf der Ausgabetheke liegt genau EIN Schnitzel (Emoji 🍖, gut sichtbar, evtl. leicht pulsierend skaliert damit es auffällt)
2. Berührt ein Spieler das Schnitzel, hebt er es auf:
   - Das Schnitzel schwebt über seinem Kopf und folgt ihm
   - Der Spieler leuchtet/markiert sich deutlich (z. B. farbiger Ring), damit jeder sieht, wer der Träger ist
   - Der Träger wird 20 % langsamer (Wert im CONFIG)
3. Es kann immer nur EIN Träger existieren
4. Vorbereitung fürs Klauen: Implementiere eine Funktion dropSchnitzel(player), die das Schnitzel vom Spieler löst, es ein kurzes Stück in eine zufällige Richtung wegfliegen lässt (mit kurzer Flug-Animation) und danach wieder aufhebbar macht. Rufe sie vorerst noch nirgends auf.

Liefere die komplette aktualisierte HTML-Datei.
```

## ✅ Abnahmetest
- Schnitzel aufheben funktioniert für beide Spieler
- Träger ist sichtbar markiert und spürbar langsamer
- Schnitzel folgt dem Träger sauber

## ⏱ Aufwand: ~20 Min
