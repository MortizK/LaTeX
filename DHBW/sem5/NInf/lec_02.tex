\subsection{Was ist Wissenschaftliches Arbeiten?}

Ein Wissenschaftlicher Artikel besteht aus:

\begin{itemize}
    \item Titel
    \item Abstrakt
    \item (Keywords)
    \item Main Text
    \item Literatur
\end{itemize}

Der Inhalt besteht meist aus:

\begin{itemize}
    \item Einleitung/ Motivation
    \item Inhalt (Grundlagen, Ansätze, Resultate, Diskussion, Verwandte Arbeiten)
    \item Zusammenfassung, Schlussfolgerungen, kritische Reflektion
\end{itemize}

Der Großteil des Textes sollten die Ansätze, Methodik und Evaluation sein.
