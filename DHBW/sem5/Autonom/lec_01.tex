\subsection{Architekturen}

Es gibt Sensoren -> Modulare Pipeline -> Aktoren

Die Modulare Pipeline kann unterschiedlich aussehen. Gängig ist:

\begin{enumerate}
    \item Perzeption
    \item Pfad Planung
    \item Regelung
\end{enumerate}

Dies kann dann beliebig Komplex durch unterschiedliche Modelle gelöst werden.

\subsection{Sensoren}

Es wird unterschieden Zwischen Passiven und Aktiven Sensoren.

Ein Passiver Sensor, wie Kamera, muss nichts senden für die Wahrnehmung.

Ein Aktiver, wie ein LiDAR, muss etwas aussenden um wahrzunehmen.
