\section{Signalverarbeitung und maschinelles Lernen}

\subsection{Signalverarbeitung}

\begin{itemize}
    \item Deterministische Signale
    \item Stochastische Signale
\end{itemize}

Maschinelles Lernen dreht sich um Stochastische Signale

\begin{itemize}
    \item Modellbasierte Signalverarbeitung (Kantendetektion in Bildern)
    \item Lernbasierte Signalverarbeitung (Erkennung handgeschriebener Zahlen)
\end{itemize}

Detektion (Gibt es ein Gesicht im Bild?) vs. Mustererkennung (Wessen Gesicht is im Bild?)

Maschine Learning kann deutlich mehr sein (Krebserkennung):

\begin{itemize}
    \item Detektion
    \item Klassifikation
    \item Zerlegung (Details)
\end{itemize}

\subsection{Maschinelles Lernen}

Ein voll autonom Fahrendes Auto ist noch eine Schwache KI. Eine Starke KI ist die Doomsday Vision von KI.

Wichtige Begriffe:

\begin{itemize}
    \item \textbf{Künstliche Intelligent}
    \item \textbf{Maschinelles Lernen}
    \item \textbf{Neuronale Netze}
    \item \textbf{Deep Learning}
    \item Regression
    \item Training
    \item Big Data
    \item Klassifikation
    \item Merkmale
\end{itemize}

Maschinelles Lernen ist ein Teil von KI, welche darauf Trainiert ist eine Art von Daten z.B. zu Klassifizieren.

Neuronale Netze sind ein subset von Maschine Learning Algorithmen, inspiriert von dem menschlichem Gehirn.

Deep Learning ist ein subset von Neuronalen Netzen. Mindestens 2 Hidden Layers.
